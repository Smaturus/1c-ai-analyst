# ADR 0005: Двухшаговая выгрузка 1С — CSV как контракт

- **Статус:** принято
- **Дата:** 2026-10-23
- **Контекст:** для подключения к 1С нужен `pywin32` и 64-битный COM-коннектор. Рабочий Python проекта (3.12, pandas 3.0.1) не содержит `pywin32`; системный Python 3.14 содержит `pywin32`, но не содержит pandas. Устанавливать пакеты в проектное окружение в рамках MVP нежелательно.

## Решение

Выгрузка 1С и анализ разделены на два шага с CSV-контрактом между ними:

1. **Выгрузка** (любой Python 3.8+ с `pywin32`, без pandas): `python onec_source.py --base ... --out-dir ... --start ... --end ...` → `sales_1c.csv` + `nomenclature_1c.csv`.
2. **Загрузка** (любой Python с pandas, без `pywin32`): `load_vitrina("1c_export/sales_1c.csv")` → витрина.

Модуль `onec_source.py` содержит оба слоя; `win32com` и `pandas` импортируются лениво, поэтому файл импортируется и запускается в обоих интерпретаторах.

## Обоснование

1. **Один контракт, два окружения:** CSV стабилен, читаем глазами, легко версионируется и проверяется.
2. **Без установки пакетов:** работает на имеющихся интерпретаторах «как есть».
3. **Тестируемость:** `load_vitrina` проверяется без 1С; `smoke_test.py` использует готовый CSV.
4. **Безопасность:** проект не получает прав на прямую запись в базу 1С; выгрузка — явный отдельный шаг.
5. **Повторяемость:** выгрузку можно перегенерировать за минуты; артефакт фиксирует состояние данных.

## Рассмотренные альтернативы

- **Установить pywin32 в рабочий Python** — отложено: не хотим менять окружение без необходимости; при желании проект работает и так (`pip install pywin32`).
- **Читать `.1CD` напрямую** — отклонено (см. [ADR 0002](0002-onec-direct-source.md)).
- **Всегда гонять выгрузку при каждом старте приложения** — отклонено: медленно, требует лицензии/прав и делает UI зависимым от 1С.

## Последствия

- В проекте два «пути запуска»: `smoke_test.py` (Excel) и `onec_source.py` (выгрузка) + `load_vitrina` (анализ).
- Формат CSV зафиксирован в [DATA_CONTRACT.md](../DATA_CONTRACT.md); изменения — только с обновлением контракта.
- При появлении `pywin32` в рабочем окружении двухшаговость можно сохранить (для воспроизводимости) или вызывать `export_from_1c` напрямую — сигнатуры уже готовы.
