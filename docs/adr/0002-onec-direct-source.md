# ADR 0002: Прямая выгрузка из 1С как основной источник для периодической аналитики

- **Статус:** принято
- **Дата:** 2026-10-23
- **Контекст:** Excel-выгрузка «Универсального отчёта» не содержит периода: дата извлекается из документа «Заказ клиента», но у 250 строк из 821 (30,5 %) эта колонка пуста — это <сумма> ₽ (24,4 % выручки). Кроме того, Excel-строки — результат группировки отчёта (821 строка против <N> записей регистра), а представления номенклатуры обрезаны. В самой базе у каждой записи регистра есть `Период` и ссылка на номенклатуру.

## Решение

Для периодической аналитики (динамика, временные ряды, сравнение периодов) **основным источником считается прямая выгрузка из 1С** (`onec_source.py` → `sales_1c.csv` → `load_vitrina`).
Загрузчик Excel остаётся **fallback** для случаев, когда база недоступна, и для сверки контрольных сумм.

## Обоснование

1. **Полнота периодов:** дата есть у 100 % строк (0 `NaT` против 250); временной ряд покрывает <сумма> ₽ вместо <сумма> ₽.
2. **Точность:** контрольные суммы совпали с Excel до копейки, значит источник совместим и не требует пересчёта методики.
3. **Гранулярность:** <N> записей регистра вместо 821 сгруппированной строки — корректная база для сравнения периодов.
4. **Товарные группы:** появляются из иерархии справочника, отдельная эвристика не нужна.
5. **Канонические имена товаров** вместо обрезанных представлений Excel.

## Рассмотренные альтернативы

- **Достраивать даты в Excel по совпадению строк** — отклонено: сгруппированные строки не имеют однозначного соответствия записям регистра.
- **Читать файл базы `.1CD` напрямую** — отклонено: нестабильный непубличный формат, риск повреждения/некорректного чтения.
- **Оставить только Excel** — отклонено: 24,4 % выручки выпадает из динамики, искажаются топы и группы.

## Последствия

- Нужен доступ к 1С (COM/`pywin32`, лицензия, права на каталог базы) и двухшаговый экспорт — см. [ADR 0005](0005-onec-export-split.md).
- В проекте хранится производный артефакт `1c_export/sales_1c.csv`: выгрузка за 2022–2024 — <N> строк (~1,2 МБ); полная выгрузка базы — <N> строк (~1,8 МБ), см. [RUNBOOK §3.3](../RUNBOOK.md#33-команда).
- Расхождение номенклатуры между источниками (96 vs 92) документировано и объясняется обрезкой представлений в Excel; канонический источник — 1С.
- Excel-путь остаётся зафиксированным тестами (контрольные суммы + smoke).
