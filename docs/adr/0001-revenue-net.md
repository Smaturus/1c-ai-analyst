# ADR 0001: Выручка без НДС как основной показатель

- **Статус:** принято
- **Дата:** 2026-10-23
- **Контекст:** в регистре «Выручка и себестоимость продаж» есть два ресурса — `СуммаВыручки` (с НДС) и `СуммаВыручкиБезНДС`. В Excel-выгрузке это колонки `X` и `Y`; ТЗ называло `X` «выручкой без НДС», что противоречит заголовку файла. Нужно выбрать показатель по умолчанию для аналитических интентов.

## Решение

По умолчанию используется **выручка без НДС** (`revenue_mode="net"`, колонка `Y` / ресурс `СуммаВыручкиБезНДС`): 19 313 936,63 ₽.
Выручка с НДС доступна режимом `revenue_mode="gross"`: 22 957 182,97 ₽.

## Обоснование

1. **НДС — не доход**, а обязательство перед бюджетом; в бухгалтерском учёте и отчёте о финансовых результатах (стр. 2110) выручка показывается без НДС.
2. **Корректная маржа:** валовая прибыль = выручка без НДС − себестоимость без НДС; при выручке с НДС маржа завышается.
3. **Сравнимость** периодов и контрагентов при разных ставках (0/10/20/22 %, спецрежимы); в рознице НДС может не выделяться.
4. **Типовые отчёты 1С** разделяют эти показатели: «Валовая прибыль предприятия» (с НДС) и «Валовая прибыль организаций» (без НДС), НДС выводится отдельным показателем «Выручка НДС».
5. **Структура регистра** подтверждает две оценки: наличие отдельного ресурса `СуммаВыручкиБезНДС`.

## Рассмотренные альтернативы

- **С НДС по умолчанию** — отклонено: искажает маржу и несравнимо между ставками.
- **Показывать обе величины всегда** — отклонено для MVP: усложняет DSL и UI; реализуется позже отдельным показателем/колонкой.
- **Автовыбор по типу контрагента/операции** — отклонено: непрозрачно и усложняет объяснение LLM-ответа.

## Последствия

- В UI и LLM-ответе показатель называется **«Выручка без НДС»**; НДС, если нужен, — отдельной строкой.
- Переключение режима — параметр загрузчика/витрины, без изменения кода интентов.
- Дословная цитата из текстов статей ИТС пока недоступна: договор developer.1c.ru («Разработчик 1С») **не включает** документацию продуктов УТ/ERP — открывается только оглавление. Для цитаты нужно зарегистрировать продукт на Портале 1С:ИТС. На принятое решение это не влияет: оно опирается на структуру регистра, типовые отчёты и публичные источники ниже.
