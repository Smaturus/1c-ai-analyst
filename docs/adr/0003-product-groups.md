# ADR 0003: Товарные группы — иерархия справочника «Номенклатура»

- **Статус:** принято
- **Дата:** 2026-10-23
- **Контекст:** в Excel-выгрузке нет колонки «товарная группа»; для интента «какие товарные группы просели» нужна группировка. Варианты: эвристика по названию, учётные разрезы 1С, иерархия справочника «Номенклатура».

## Решение

Группа товара = **ближайшая группа-родитель** в иерархии справочника «Номенклатура» (`Родитель`), полный путь группы сохраняется отдельной колонкой `product_group_path`.
Если колонки `product_group` в витрине нет (Excel-режим), используется эвристика `derive_product_group` — первое слово названия (fallback, а не основной путь).

## Обоснование

1. Это **стандартный способ группировки продаж в 1С**: в документации УТ 11.5 есть отдельные разделы «Группы номенклатуры» и «Виды номенклатуры»; для группировки используется именно иерархия.
2. «Виды номенклатуры» — учётная типизация (товар/услуга/набор, счета, НДС), не разрез продаж.
3. «Товарные категории» — маркетинговый разрез (планы, скидки, ассортимент), дополнительный, не замена иерархии.
4. Ближайшая группа даёт осмысленные бизнес-категории («Аксессуары», «Кухонные электроприборы», «Кондитерские изделия»), а полный путь — возможность подняться на уровень выше.
5. В базе `<копия базы>` это подтверждено на данных: 27 групп у товаров (всего 61 группа в иерархии), 16 встречаются в периоде 2022–2024; «Без группы» — 14 строк (<сумма> ₽).

## Рассмотренные альтернативы

- **Первое слово названия (эвристика)** — только fallback для Excel: даёт 52 «группы», среди которых коды и обрезки (`Х-1234`, `SH-10`, `Комиссионное`), плохо для бизнес-отчёта.
- **Вид номенклатуры** — слишком грубо (собственный/комиссионный/работа).
- **Товарные категории** — в демо-базе не заполнены; зависят от маркетинговой настройки.

## Последствия

- `attach_product_group` больше не перезаписывает готовую колонку из 1С: заполняет только пустые значения эвристикой.
- `get_group_dynamics(group_by=None)` по умолчанию использует `product_group`, если она есть, иначе — эвристику.
- В CSV добавлены `product_group` и `product_group_path`; `nomenclature_1c.csv` содержит полную иерархию (<N> позиции, 61 группа).
- При появлении справочника товарных групп (или иной иерархии) достаточно передать колонку/Series/callable в `group_by` — сигнатура не меняется.
