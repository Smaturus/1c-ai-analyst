# Заметки по доступу к ИТС

Документ фиксирует результаты проверки ИТС под профилем пользователя (2026-10-23), причины ограничений и дальнейшие действия. Нужен, чтобы не повторять диагностику в новых чатах.

## 1. Что проверялось

Задача — получить первоисточник ИТС по двум методическим вопросам:

1. Какой показатель выручки использовать для управленческой аналитики продаж — с НДС или без НДС.
2. Что считать «товарной группой» для группировки продаж.

## 2. Инфраструктура доступа

- Сайт `its.1c.ru` доступен: DNS `185.12.155.120`, TCP 443 открыт, HTTP 200. **VPN и прокси не используются** (`ProxyEnable=0`, WinHTTP — direct access).
- Для входа открывалось отдельное окно Chrome с временным профилем и `--remote-debugging-port` (Playwright/MCP не понадобились: Node 24 + CDP). Вход выполнил пользователь; логин/пароль не запрашивались и не сохранялись.
- Временный профиль с куками после работы удалён, окно закрыто.

## 3. Что показал профиль

| Параметр | Значение |
|---|---|
| Пользователь | `smatu` |
| Профиль ИТС | «Разработчик 1С» |
| Договор | «Доступ для пользователей developer.1c.ru», до **14.10.2027** |
| Документация продуктов | **не входит** в этот доступ |

Документация УТ 11.5 / ERP 2.5 открывается только на уровне оглавления; каждая статья отдаёт:

> «Доступ к данному материалу ограничен. Доступ к документации по программным продуктам предоставляется пользователям, которые зарегистрировали этот продукт на Портале 1С:ИТС.»

Поиск по ИТС у профиля работает, но по запросам о выручке/НДС/группах выдаёт только «Информацию об обновлениях» — тексты документации не отдаются.

## 4. Что удалось подтвердить по оглавлению (без текста статей)

- [«Группы номенклатуры»](https://its.1c.ru/db/ut115doc/bookmark/Goods/GoodsGroups) — отдельный раздел; группировка продаж идёт по группам справочника «Номенклатура».
- [«Виды номенклатуры»](https://its.1c.ru/db/ut115doc/bookmark/Goods/GoodsTypes) — отдельный раздел; вид номенклатуры — учётная типизация, не группировка продаж.
- [«4.13. Отчеты по продажам»](https://its.1c.ru/db/ut115doc/bookmark/Salesreports/Salesreports) — раздел отчётов по продажам.
- [«Валовая прибыль предприятия/Валовая прибыль организаций»](https://its.1c.ru/db/ut115doc/bookmark/Salesreports/Salesreports1) — два отчёта; по публичному разбору первый включает НДС, второй — без НДС.
- [«Выручка НДС»](https://its.1c.ru/db/ut115doc/bookmark/Salesreports/Salesreports23) — НДС выводится отдельным показателем, то есть «выручка» и «НДС» — разные величины.

## 5. Подтверждающие публичные источники

- БухЭксперт8: «В отчете Валовая прибыль предприятия — Выручка включает НДС, во втором указана без НДС. Колонку с суммой НДС можно вывести отдельно» — https://buhexpert8.ru/voprosy/voprosy-1s-ut/formirovanie-otcheta-10.html
- ОФР, стр. 2110 — выручка без НДС — https://www.4dk.ru/content/art/36689-cplus-otchet-o-finansovyih-rezultatah-za-2025-god-obrazets-zapolneniya-i-rasshifrovka-strok-20260303
- НДС в управленческом учёте — https://www.fd.ru/articles/164792-nds-v-upravlencheskom-uchete-zachem-ochishchat-otchetnost-statgb
- Инфостарт: выручка без НДС = 90.01 минус НДС — https://infostart.ru/1c/reports/846969/
- Структура регистра в самой базе: ресурсы `СуммаВыручки` (с НДС) и `СуммаВыручкиБезНДС` — прямое подтверждение двух оценок.

## 6. Как получить дословную цитату ИТС

1. В личном кабинете ИТС → «Договоры и сервисы ИТС» → «зарегистрированные программные продукты» зарегистрировать УТ 11.5 (или ERP 2.5).
2. После этого статьи документации откроются; повторная проверка занимает несколько минут (нужен повторный вход, временный профиль создаётся заново).
3. Альтернатива без входа: пользователь копирует текст статьи в чат или сохраняет страницу в PDF в папку проекта — тогда цитата переносится в [REPORT.md](REPORT.md)/[ADR 0001](adr/0001-revenue-net.md).

## 7. Вывод

Отсутствие доступа к текстам ИТС **не меняет** методическое решение: выручка для аналитики — без НДС, товарные группы — иерархия номенклатуры. Решение подтверждено структурой регистра, типовыми отчётами и публичными источниками; при появлении доступа к документации ИТС ссылки будут добавлены в отчёт и ADR.
