# Инструкция: локальный запуск UI и приёмка

Документ для проверки Streamlit-интерфейса (`app.py`) на синтетических демо-данных. Базовый набор из пяти вопросов плюс расширенные сценарии (L4L, возвраты, фильтры) покрывают семь интентов; для каждого указан ожидаемый интент и что должно быть на экране.

## 1. Предусловия

- Python 3.12+ (в репозитории проверено на 3.12 и 3.14).
- Зависимости: `pandas`, `streamlit`, `pydantic` (см. [`requirements.txt`](../requirements.txt)).
- Демо-данные: [`sample_data.csv`](../sample_data.csv) (600 строк, 2023–2024, 10 % возвратов) — генерируются `generate_synthetic_data.py`; реальные выгрузки 1С в репозитории отсутствуют.
- Ключ LLM **не обязателен**: без `LLM_PROVIDER` приложение работает в офлайн-режиме правил.

## 2. Запуск

```powershell
cd 1c-ai-analyst
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt

# офлайн-режим (правила, без ключа)
.\.venv\Scripts\python -m streamlit run app.py
```

С LLM (DeepSeek / GigaChat / OpenAI / Ollama) — задать переменные и перезапустить.
Если настроить несколько провайдеров одновременно (`LLM_API_KEY` + `LLM_API_KEY_GIGACHAT`),
в сайдбаре появится переключатель **«Провайдер LLM»**:

```powershell
$env:LLM_PROVIDER = "deepseek"        # openai | deepseek | ollama | gigachat
$env:LLM_API_KEY  = "sk-..."
$env:LLM_MODEL    = "deepseek-v4-flash"
.\.venv\Scripts\python -m streamlit run app.py
```

По умолчанию открывается `http://localhost:8501`; в сайдбаре выберите источник **«Демо-данные: sample_data.csv»** (это синтетическая витрина с полными датами и товарными группами).

## 3. Пять контрольных вопросов

Вводите вопрос в поле и нажимайте «Спросить» **или клавишу Enter**. Если вопрос неоднозначный, появляются кликабельные варианты уточнения (Quick Replies): клик подставляет текст в поле и отправляет вопрос автоматически. Ожидания — для демо-источника и офлайн-режима (в LLM-режиме интент должен совпадать, формулировки могут отличаться).

| # | Вопрос | Ожидаемый интент | Что должно быть на экране |
|---|---|---|---|
| 1 | `Какие 10 товаров продаются хуже остальных за 2024 год?` | `top_bottom_products` | Таблица 10 строк (`rank`, `product`, `revenue`, `share_pct`), горизонтальный бар: ось Y «Товар», X «Выручка без НДС, ₽», сортировка по значению; худший — «Кабель Iota», 145 600,00 ₽ |
| 2 | `Как менялись продажи по месяцам в 2023 году?` | `timeseries` | Таблица 12 строк (`period`, `revenue`), линия: оси «Период» / «Выручка без НДС, ₽»; сумма ряда **47 454 600,00 ₽** |
| 3 | `У каких контрагентов упали продажи в 2024 по сравнению с 2023?` | `counterparty_dynamics` | Таблица 6 строк (`counterparty`, `period1_value`, `period2_value`, `delta`, `delta_pct`, `direction`), горизонтальный бар по `delta`: оси «Контрагент» / «Изменение, ₽», бары окрашены по направлению; лидер падения — «ООО Лютик» −1 501 800,00 ₽ |
| 4 | `Какие товарные группы просели в 2024 по сравнению с 2023?` | `group_dynamics` | Таблица 1 строка, только падения (`only_drops`); горизонтальный бар: ось Y «Товарная группа», X «Изменение, ₽»; «Аксессуары» −731 100,00 ₽ |
| 5 | `Сколько мы продали за 2024 год?` | `total` | Одна строка: выручка **52 253 500,00 ₽**, количество **2 618**, строк **300**, без даты **0**; три `st.metric` |

**Регрессия исправленного бага (обязательно):** спросите
`Какие товары продаются хуже остальных за 2024 год, топ 5?`
Ожидается **5 строк** и `limit: 5` в JSON-DSL. До исправления возвращалось 202 строки (`limit: 202` из «2024»).

## 4. Дополнительные проверки

| Проверка | Действие | Ожидание |
|---|---|---|
| Уточнение | `Покажи что-нибудь интересное` | синий блок «Нужно уточнение» и кликабельные варианты (pills), без ошибки |
| Отправка по Enter | ввести вопрос в поле и нажать Enter (без кнопки «Спросить») | вопрос отправлен, результат построен; «✖️» по-прежнему только очищает поле |
| Quick Replies | `Покажи что-нибудь интересное` → выбрать вариант | вариант подставляется в поле и вопрос отправляется автоматически |
| Умный выбор текста | `продажи` → выбрать «Сколько мы продали за 2024 год?» | в поле остаётся **только** полный вопрос (без склейки с «продажи»), результат «Итог за период» |
| Склейка фрагмента | `У каких контрагентов выросли продажи?` → выбрать «2023 и 2024» | в поле склейка «У каких контрагентов выросли продажи? 2023 и 2024», «Динамика контрагентов» |
| Лимит уточнений (graceful degradation) | задать составной запрос `топ-5 товаров за 2023 и топ-5 товаров за 2024` и отвечать на уточнения | не более 2 уточнений подряд, затем жёлтая плашка «Уточнения исчерпаны — показываю как понял…» и один топ за диапазон 2023–2024; JSON — в «Технических деталях» |
| Уточнение периода | `У каких контрагентов выросли продажи?` | уточнение с недостающими `period1`/`period2` |
| Fallback | ввести бессмыслицу (`asdf qwerty`) | дружелюбная ошибка + список доступных интентов с примерами |
| JSON-DSL | раскрыть «Технические детали» | валидный JSON `{"intent": ..., "params": {...}}` в блоке с кнопкой копирования (правый верхний угол), режим `LLM` или `офлайн-правила` |
| Качество данных | источник «Демо-данные: sample_data.csv» | в сайдбаре 0 строк без даты и 60 строк с отрицательной выручкой |
| Смена источника | переключить демо-данные → загрузка файла | таблица пересчитывается после загрузки своего CSV/Excel, нет падения |
| Пустой вопрос | нажать «Спросить» без текста | предупреждение «Введите вопрос» |
| Режим LLM | выключить переключатель «Использовать LLM» | ответ приходит без вызова API, в «Технических деталях» режим `офлайн-правила` |
| Относительные даты (LLM) | при включённой LLM: `Сколько продали в позапрошлом году?` | в JSON-DSL период на два года раньше текущей даты (в промпте есть Few-Shot примеры с этой же датой) |
| Относительные даты (офлайн) | выключить LLM и спросить `Какие топ-5 товаров продавались лучше всего в марте позапрошлого года?` | интент «Топ/антитоп товаров», период — март года, который был два года назад, 5 строк |
| Сравнение относительных периодов | `У каких контрагентов упали продажи в прошлом году по сравнению с позапрошлым?` | интент «Динамика контрагентов», `only_drops=true`, period1 — позапрошлый год, period2 — прошлый |
| Очистка поля | ввести текст и нажать «✖️» рядом с полем | текст очищен, введённый ранее вопрос не отправляется |
| Лояльные формулировки | `Динамика по месяцам за 2023` | интент «Временной ряд продаж», 12 месяцев 2023 — без слова «продажи» |
| Сравнение топов (L4L) | `Сравни топ-5 товаров за 2023 и 2024 годы` | интент «Сравнение топов (L4L)»: таблица `Место 2023`, `Место 2024`, `Товар`, выручка за оба года, «Изменение», «Статус» (🔵 вошёл, 🔴 выпал, 🟢 поднялся, 🟠 опустился, ⚪ то же место) и grouped bar по двум периодам |
| Отрицательная выручка (возвраты) | `покажи товары с отрицательной выручкой за 2024` | интент «Отрицательная выручка / возвраты»: в таблице только отрицательные суммы (`revenue < 0`), колонки «Сумма», «Строк», «Количество»; сводка «Общая сумма возвратов: … ₽ (N строк)»; красные горизонтальные бары |
| Фильтр по товару | `Сколько продали «Телевизор Zeta» за 2024` | интент «Итог за период», выручка 11 990 000,00 ₽; сводка начинается с «По фильтру «Телевизор Zeta» найдено 1 записей.» |
| Фильтр по группе | `Топ-5 товаров в группе «Аксессуары» за 2024` | интент «Топ/антитоп товаров» с `group_filter`: в таблице только товары группы «Аксессуары», в сводке — упоминание фильтра |
| Минимальная база | `У каких контрагентов выручка в 2023 была больше 100к и упала в 2024` | «Динамика контрагентов» с `min_base_revenue=100000`: остаются только контрагенты с выручкой 2023 ≥ 100 000 ₽ |
| Средний чек | `Сравни средний чек за 2024` | «Нужно уточнение: Расчёт среднего чека не поддерживается. Доступны только суммарная выручка и количество.» |
| Пустой период | `Динамика по месяцам за 2030` | «За выбранный период данных нет. В текущем источнике данные доступны с 01.01.2023 по 28.12.2024.» |
| Фильтр без совпадений (total) | `Сколько продали «НетТакого» за 2024` | «По фильтру «НетТакого» данных не найдено за выбранный период.» — без противоречия «найдено 1 записей… строк 0» |
| Период по умолчанию (офлайн) | `Сколько продали` (без дат) | период 2023-01-01…2024-12-31 (или диапазон из профиля данных), итог по демо-витрине 99 708 100,00 ₽ |
| LLM не настроена | запуск без `LLM_API_KEY` | переключатель заблокирован, в сайдбаре «Офлайн-режим» |
| Графики: оси | `топ-10 по количеству за 2024` | горизонтальный бар, оси «Товар» / «Количество, шт.», длинные названия товаров не обрезаны, лидер сверху |
| Графики: линия | `динамика по месяцам за 2023` | линия, оси «Период» / «Выручка без НДС, ₽» |
| Графики: цвет | `динамика контрагентов за 2023 и 2024` | горизонтальный бар, оси «Контрагент» / «Изменение, ₽», бары окрашены по направлению (легенда «Направление») |
| Индикатор расчёта | задать любой вопрос | плашка «Разбираю вопрос…» появляется **над** таблицей результата (не под ней) и исчезает после ответа |

## 5. Чек-лист приёмки

- [ ] UI запускается без ошибок, сайдбар показывает качество данных.
- [ ] Вопросы 1–5 дают ожидаемые интенты и таблицы.
- [ ] Регрессия «год + топ 5» — 5 строк.
- [ ] Графики: горизонтальные бары для топов/динамики (ось Y — категория, `sort="-x"`, лидер сверху), линия для временного ряда; подписи осей русские («Товар», «Контрагент», «Период», «Количество, шт.», «Выручка без НДС, ₽»).
- [ ] Таблица показывает русские заголовки (Товар, Выручка без НДС, Период…), без технических имён полей.
- [ ] Клик по заголовку сортирует столбец: числа — по значению, даты — по дате, товары — по алфавиту.
- [ ] Переключатель «Использовать LLM»: активен при ключе, заблокирован без него; при выключении режим — `офлайн-правила`.
- [ ] Свёрнутый блок «Технические детали» показывает JSON-DSL.
- [ ] Уточнение и fallback работают без трейсбеков.
- [ ] При наличии ключа LLM: те же вопросы дают те же интенты, в блоке указан режим `LLM`.
- [ ] Плашка «Разбираю вопрос…» видна **над** таблицей результата, а не под ней.

## 6. Если что-то не так

| Симптом | Решение |
|---|---|
| `ModuleNotFoundError: streamlit/pydantic` | активировать `.venv` и `pip install -r requirements.txt` |
| «Не удалось разобрать вопрос» | проверить `LLM_PROVIDER`/ключ или повторить в офлайн-режиме |
| Неверный интент в LLM-режиме | сменить модель (`LLM_MODEL`), вопрос переформулировать; офлайн-правила — эталон для 5 вопросов |
| График не появился | проверить, что источник — демо-данные (там есть `date` и `product_group`) |
| Порт занят | `streamlit run app.py --server.port 8502` |

**Примечание:** UI проверялся локальным запуском Streamlit (Windows). Автотесты: `python -m pytest` (319 проверок в `tests/`), `smoke_llm.py` (92 проверок), `smoke_test.py` (PASSED).
